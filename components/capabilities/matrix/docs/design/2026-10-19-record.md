# matrix 0.6.0: design record, 2026-10-19

The judgments made building matrix 0.6.0, recorded by the crafting-aces procedure (its
`SKILL.md`, and `references/ports-and-adapters.md`, `interface.md`, `composition-root.md`).
Rows take the skill's form: claim, test, verdict, named weakness or measure, evidence.
Evidence tags: *observed* (read or run on this tree today), *reported* (a dated document),
*inferred*, *hypothesis*. "The audit" is
`scratch/research-matrix-ix-landscape/2026-10-19/cli-api-audit.md` (reported).

Provenance carried from the skill: the ports-and-adapters layout rests on one author and one
adopting study; the composition root driven by configuration is the ACES framework's
practice, not the canon's; stasis, drag and opacity are that framework's model. Nothing here
is called ACES compliant except as a claim in four parts.

## 13. Agent runtimes and model runtimes, split (2026-10-22)

One port, one registry point and one reply type had carried two conversations: an agent
session (a loop, tools, turns) and one model call through hardline (*reported*:
`scratch/review-2026-10-22/matrix.md`, area 4). The port's own docstring named the mismatch:
`check` existed to refuse "a single-call runtime handed tools". The model runtime's `check`
refused definitions the claude-sdk runtime's accepted, a strengthened precondition, so it was
no substitute under interface D24 (Liskov and Wing); and it filled `num_turns=1` and
`stop="completed"` with constants, so a truncation or a refusal could never show, while the
facts a call does have (request id, attempts, fallback) had no slot. yzavyas ruled the split
(Q5, and the Phase 4 design of `scratch/PLAN-2026-10-22-final-components.md`).

## 14. Provenance: what a call and a session carry (2026-10-22)

A model's reply is a sample, so a reader of the record must be able to tell which model gave
it, how, and whether it is a whole answer. The review found matrix keeping part of what its
runtimes reported and stamping constants over the rest (*reported*:
`scratch/review-2026-10-22/matrix.md`, area 3; `full/matrix-src.md` F9, F10, F30;
`full/matrix-tests.md` findings 4 and 11). hardline 0.2 now reports a call's whole record
(its `docs/design/2026-10-22-record.md`), and this section records how matrix carries it.
