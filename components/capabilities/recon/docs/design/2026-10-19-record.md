# recon 0.11.0: design record, 2026-10-19

The judgments made bringing recon to the shared exit-code and error contracts, the CLI and
API audit's findings (S12, S13, S14, S15, N1, N2, N8) and telemetry on OpenTelemetry. The
form is `crafting-aces`' record: one row per judgment, the test it answers to with its
mark, a verdict, the named weakness or measure, and tagged evidence. Paths are relative to
`components/capabilities/recon/`; "audit" is
`scratch/research-matrix-ix-landscape/2026-10-19/cli-api-audit.md` (reported, 2026-10-19).

## The claim

R(recon's public surface: the CLI, `import recon`, the `recon.v1.*` documents, the archive
layout; Y: an agent or program driving recon acts on one error shape, one exit table and
one problem vocabulary shared with matrix and ix, and can see what a survey did without
reading code; W: a sibling tool's agent reading recon's output, a program calling the
library from another directory, an operator pointing telemetry at a collector of their
choosing; M: the contract tests in `tests/test_cli.py` (`test_the_agreed_kinds_keep_their_
agreed_codes`, `test_the_shared_problem_kinds_are_the_agreed_ones`) pass, and every audit
finding listed has a regression test that failed before its fix). aces-claims T1, T2
(attested): the four parts are present. The procedure ran on an existing component, so
steps 2 and 3 were asked as questions of the layout already there; step 9 (slick manifest)
is pending: `slick` was not run, and no manifest was written from memory.
