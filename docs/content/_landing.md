A component registry is a catalog of decisions. Each entry records what a thing provides — a declared surface legible enough that an agent can decide to compose two components it has never run, from their manifests alone. Mastery distilled once, available to every project that follows.

gnx is that catalog by design: a registry of manifests, a Claude Code marketplace, and a CLI (`gnx`) that initializes projects through conversation rather than fixed menus. The loop is precise: an agent will search, compose what fits, and whatever enters the catalog extends what the next search reaches.

What the loop cannot generate is trust. Accreditation in gnx is designed to be human-ratified — a status the agent can read and build on, but cannot mint. The catalog grows through agents; it is governed by the people who built what the agents compose from.
